# 🍄 버섯숲의 전설 — 실시간 협동 RPG

기존 **버섯숲의 전설** 픽셀 RPG를 2~8명이 함께 플레이할 수 있게 확장한 프로젝트입니다. 기존 주황버섯 도트, 숲 맵, NPC, 퀘스트, 조작 방식을 유지했습니다.

## 빠른 실행 (Windows)

1. [Node.js](https://nodejs.org/) **20 이상**을 설치합니다. 설치 후 컴퓨터를 한 번 재시작하거나 새 터미널을 여세요.
2. 프로젝트 ZIP을 압축 해제한 뒤 `START_WINDOWS.bat`을 더블클릭합니다.
3. Chrome/Edge에서 **http://localhost:3000** 에 접속합니다.
4. 닉네임을 입력하고 **새 방 만들기**를 누른 뒤, 화면 위쪽의 **초대 링크 복사** 버튼으로 친구에게 주소를 공유합니다.
5. 친구는 링크로 접속해 닉네임을 입력하고 **방 입장**을 누르면 됩니다. 친구가 직접 접속한 주소가 다른 경우에도 **초대 코드 5자리**로 참여할 수 있습니다.

Windows 터미널이나 macOS/Linux에서는 다음과 같이 실행할 수도 있습니다.

```bash
cd mushroom_forest_multiplayer
npm start
```

서버 종료: 터미널에서 `Ctrl+C`.

**npm install은 필요 없습니다.** 런타임에서 사용하는 것은 Node.js 기본 모듈뿐입니다. 테스트는 Node.js 22 이상에서 실행하는 것을 권장합니다.

## 친구와 실제로 접속하는 방법

### 같은 와이파이 / 같은 LAN

- 서버를 실행한 사람은 Windows 명령 프롬프트에서 `ipconfig`를 입력해 Wi-Fi 또는 이더넷의 **IPv4 주소**(예: `192.168.0.20`)를 확인합니다.
- 친구가 접속할 주소는 `http://192.168.0.20:3000`과 같은 형태입니다. **`localhost`는 서버를 실행한 컴퓨터에서만 작동합니다.**
- Windows 방화벽 알림이 뜨면 **개인 네트워크**에서 Node.js를 허용해야 할 수 있습니다.
- 같은 공유기라도 게스트망·클라이언트 격리 기능이 켜져 있으면 연결되지 않을 수 있습니다.
- 서버 실행자는 `http://localhost:3000`으로 접속할 수 있습니다.

### 서로 다른 집 / 인터넷 접속

로컬 PC의 주소를 그대로 보내면 외부 인터넷에서 접속할 수 없습니다. WebSocket을 지원하는 **Node.js 웹 호스팅**(HTTPS와 WSS를 지원)에 프로젝트를 배포하거나 적절히 설정된 터널 서비스 등을 사용해야 합니다.

호스팅 기본 설정:

- 실행 명령: `npm start` 또는 `node server.js`
- 포트: 호스팅에서 주입하는 `PORT` 사용 (기본 3000)
- 헬스체크: `/health`
- WebSocket 엔드포인트: `/ws` (동일 호스트)
- 서버는 **단일 인스턴스**에서 동작하게 배포합니다. 여러 인스턴스로 분산하면 방 데이터가 서로 공유되지 않습니다.
- HTTPS 호스팅에서는 브라우저가 자동으로 `wss://`로 연결합니다.

실제 호스팅·공개 주소는 이 패키지에 포함되어 있지 않습니다.

## 플레이 방법

| 조작 | 기능 |
| --- | --- |
| WASD 또는 방향키 | 이동 |
| Space | 앞의 몬스터 공격 |
| E | NPC와 대화 |
| Q | 회복 물약 사용 |
| 채팅 입력창 + Enter | 채팅 전송 |
| 모바일 | 방향키 및 공격·대화·회복 터치 버튼 |

진행 순서:

1. 새 방을 만들고 1~7명의 친구를 초대합니다(최대 8명).
2. 팀 전체가 **주황버섯 5마리**를 처치합니다.
3. 마을의 **루나**에게 다가가 E를 누릅니다. 팀 전원 보상, 동쪽 숲 보스가 개방됩니다.
4. 동쪽의 **거대 주황버섯**을 함께 처치하면 퀘스트가 완료됩니다.
5. 마을의 **토비**에게서 물약을 15G에 구매할 수 있습니다.

## 설계와 현재 범위

- **실시간 WebSocket**: 방 안의 플레이어 위치, 공격, 몬스터 체력, 몬스터 AI, 사망·부활, 퀘스트 진행, 채팅을 공유합니다.
- **서버 권한 방식**: 이동 가능 여부, 이동·공격 간격, 사거리, 데미지, 아이템 구매, 경험치/골드를 서버가 판정합니다. 클라이언트는 행동 요청만 전송합니다.
- **방마다 최대 8명**: 1명으로 방을 먼저 만들어 친구를 기다릴 수 있습니다. 협동 플레이는 2~8명용입니다.
- **보상 공유**: 몬스터와 보스를 처치하면 살아 있는 방 참여자들에게 경험치/골드가 지급됩니다. 루나의 퀘스트 보상은 방 전체에 지급합니다.
- **동일 방 맵 공유**: 몬스터 상태는 같은 방 모든 사람에게 동일하지만, 다른 방끼리는 독립입니다.
- **접속 해제 시**: 퇴장한 캐릭터는 방에서 사라지고, 남은 사람이 있으면 방은 유지됩니다.
- **서버 재시작/빈 방**: 플레이 데이터와 방 진행 기록은 메모리에만 보관되어 사라집니다. **로그인, 영구 저장, 계정 복구는 아직 구현되지 않았습니다.**
- **간이 방 코드**: 방 코드는 초대 수단이며 보안 비밀번호가 아닙니다. 공개 서비스화하려면 인증, 개인정보 정책, 저장소, 모니터링 및 추가 운영 보안이 필요합니다.

## 테스트

```bash
npm test
```

실제 WebSocket 접속을 사용하여 **2명 입장/이동/채팅/퇴장**, **9번째 입장 제한/조작 검증**, **공유 퀘스트/보스 처치/공동 보상**을 자동 검증합니다.

## 서버 설정

```bash
# 기본 설정
node server.js

# 환경변수 사용 예시 (macOS/Linux)
PORT=8080 HOST=0.0.0.0 node server.js

# Windows PowerShell
$env:PORT=8080; node server.js
```

`HOST=0.0.0.0`은 같은 네트워크의 장치로부터 접속을 허용합니다. 외부 접속이 필요한 경우 신뢰할 수 있는 호스팅과 방화벽 구성을 사용하세요.
